# 🏪 Sistem Informasi Pengelolaan UD HANA

Sistem Informasi UD HANA merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan operasional usaha, khususnya dalam pencatatan transaksi keuangan serta pengelolaan data produk dan layanan.

## ✨ Fitur Utama

### 1. Dashboard
- Menampilkan ringkasan informasi usaha.
- Informasi pemasukan dan pengeluaran.
- Ringkasan aktivitas operasional.

### 2. Manajemen Produk
- Pengelolaan data produk.
- Menambahkan, mengubah, dan menghapus data produk.

### 3. Manajemen Layanan
- Pengelolaan data layanan usaha.
- Menambahkan, mengubah, dan menghapus data layanan.

### 4. Manajemen Keuangan
- Pencatatan pemasukan.
- Pencatatan pengeluaran.
- Pengelolaan riwayat transaksi.
- Pemantauan kondisi keuangan usaha.

## 🛠️ Teknologi

- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## 🎯 Tujuan Pengembangan

Membantu proses administrasi usaha UD HANA melalui sistem terkomputerisasi sehingga pencatatan transaksi dan pengelolaan informasi usaha menjadi lebih terstruktur dan mudah dikelola.
